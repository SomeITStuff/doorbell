# doorbell — мини-апп домофона (Telegram WebApp + WebRTC)

Клиентская часть домашнего домофона на базе панели **ML-20IP**: открывается как
Telegram WebApp из бота — видео и звук с панели, микрофон (обратная связь),
кнопка двери, скриншот и запись видео прямо в чат.

**Адрес:** https://someitstuff.github.io/doorbell/

## Состав

| Файл | Назначение |
|---|---|
| `index.html`, `app.js`, `style.css` | приложение |
| `version.json` | текущая сборка (по нему ссылки сами обновляются) |
| `vNN/` | замороженные сборки для старых закладок; устаревшие перенаправляются через `404.html` |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

## Как это работает

- Сигналинг WebRTC — через Firebase RTDB (обмен SDP/ICE), медиа идёт напрямую (P2P).
- Источник видео — go2rtc на «коробке» рядом с панелью.
- Команды двери/скриншота/записи передаются через RTDB, файлы приходят в Telegram.

Серверная часть (бот, мост, go2rtc, docker-образ) в этот репозиторий не входит.

## Обновление

Из основного проекта: `python3 deploy_miniapp.py` — одна сборка, один коммит.
